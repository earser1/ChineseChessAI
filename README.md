项目简介
本项目是为吉林大学软件工程课程作业开发的中国象棋智能对弈AI，基于C++语言实现，严格适配Botzone在线对战平台的JSON交互协议，支持棋盘状态解析、合法走法生成、局面估值、Alpha-Beta剪枝决策等核心功能，可在Botzone平台完成自动匹配对局，同时支持本地编译调试，便于团队协作开发与功能迭代。
项目采用多人协作模式，通过GitHub进行版本管理，队友通过Fork仓库、提交修改、发起Pull Request（PR）的方式参与开发，确保代码同步与协作规范。
运行环境
- 编程语言：C++（推荐C++11及以上标准）
- 编译工具：支持GCC、Clang等主流C++编译器
- 运行平台：Botzone在线对战平台 / 本地终端（Windows、Linux、macOS均可）
- 依赖环境：无额外第三方依赖，仅使用C++标准库
项目结构
├── main.cpp        # 主程序入口，负责Botzone JSON协议交互（读取输入、输出落子）
├── chess.h         # 棋盘类头文件，定义棋盘结构、棋子常量、棋盘初始化/更新方法
├── chess.cpp       # 棋盘类实现，处理棋盘状态维护、棋子合法性校验
├── move.h          # 走法生成头文件，声明合法走法生成、落子验证相关函数
├── move.cpp        # 走法生成实现，基于中国象棋规则生成所有合法走法
├── eval.h          # 估值函数头文件，声明局面评分、棋子价值评估函数
├── eval.cpp        # 估值函数实现，自定义棋子价值体系，评估当前局面优劣
├── search.h        # 搜索算法头文件，声明Alpha-Beta剪枝、极大极小搜索函数
├── search.cpp      # 搜索算法实现，优化搜索效率，生成最优落子决策
└── README.md       # 项目说明文档，包含协作方式、使用指南、项目说明
核心功能
- 棋盘管理：实现中国象棋标准棋盘初始化、棋子摆放，支持根据对手落子更新棋盘状态，实时校验棋子位置合法性。
- 走法生成：严格遵循中国象棋规则（将/帅、士、象、马、车、炮、兵的走法限制），自动生成当前局面下所有合法落子。
- 局面估值：自定义棋子价值权重（如车>炮>马>象>士>兵），结合棋盘位置、棋子威胁等因素，对当前局面进行量化评分。
- 决策优化：采用Alpha-Beta剪枝算法优化极大极小搜索，减少无效搜索分支，提升AI决策速度与准确性。
- Botzone适配：完全遵循Botzone平台JSON输入输出规范，通过标准输入（cin）读取对局信息，标准输出（cout）输出落子结果，可直接上传平台参与对战。
使用方法
1. 本地调试与开发
# 1. 克隆本仓库到本地（若为协作成员，先Fork仓库后克隆自己的Fork版本）
git clone https://github.com/你的GitHub用户名/仓库名.git

# 2. 进入项目目录
cd 仓库名

# 3. 编译代码（以GCC为例）
g++ *.cpp -o chess-ai -std=c++11

# 4. 运行程序（本地调试可模拟Botzone输入，或直接运行测试）
./chess-ai
2. Botzone平台上传与对战
1. 登录Botzone平台（https://www.botzone.org.cn/），创建新机器人，选择“中国象棋”项目。
2. 上传项目所有.cpp和.h文件（无需上传编译后的可执行文件）。
3. 设置编译命令：g++ *.cpp -o main -std=c++11，保存并编译。
4. 编译成功后，即可在Botzone平台发起对局，AI将自动响应并完成对弈。
